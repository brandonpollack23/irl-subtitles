# Speechmatics from a browser origin: desk probe (irl-subt-3xb.4)

2026-09-15, from a Linux desktop (curl and Node 22's WebSocket), with `Origin: http://localhost:5174` and no
Speechmatics account. **Not yet run on the Even app** (Android, iOS, simulator): use the probe's Speechmatics tab
(`src/panels/SpeechmaticsPanel.tsx`) with a real key and record reports next to this file.

## What the desk probe showed

| Check | Result |
| --- | --- |
| CORS preflight `POST https://mp.speechmatics.com/v1/api_keys?type=rt` (and `type=batch`) | 200, origin reflected, `Authorization, Content-Type` allowed |
| Unauthorized `POST mp.speechmatics.com/v1/api_keys` | **401 without `Access-Control-Allow-Origin`**: a browser sees a bare `TypeError`, indistinguishable from offline or a whitelist block. Test keys elsewhere. |
| CORS preflight `https://asr.api.speechmatics.com/v2/jobs` (and `eu1.asr.api…`) | 200, origin reflected |
| Unauthorized `GET asr.api.speechmatics.com/v2/jobs?limit=1` | 401 **with** CORS headers, so a browser can read the status: the key test uses this call |
| Realtime hosts | `eu.rt`, `eu2.rt`, `neu.rt` → EU proxy; `us.rt`, `us2.rt` → US proxy; `global.rt` → traffic manager |
| `wss://eu.rt.speechmatics.com/v2?jwt=bogus` | Upgrades (101), then on StartRecognition sends `{"message":"Error","type":"not_authorised","reason":"Not Authorized"}` and closes 4001 |
| Soniox async (`https://api.soniox.com/v1/files`, `/v1/transcriptions`) preflight | 200, `Access-Control-Allow-Origin: *`, `DELETE, GET, OPTIONS, POST`; 401 bodies carry CORS headers (for irl-subt-3xb.8) |

Docs checked the same day: `transcription_config.model` (`standard`/`enhanced`) replaces the deprecated
`operating_point`; `SpeakersResult` is `{speakers: [{label, speaker_identifiers: [...]}]}`; json-v2 batch output has
the same top-level `speakers` array when `get_speakers` is set; enrolled speakers keep their label, others get S1, S2…;
at most 50 identifiers per session.

## Chosen for the implementation

- Realtime: temporary key from `POST mp.speechmatics.com/v1/api_keys?type=rt` (`{ttl}` → `key_value`), then
  `wss://<region>.rt.speechmatics.com/v2?jwt=…`; region `eu` by default. A temporary key failing with a bare network
  error is reported as "rejected the key, or unreachable".
- Batch: Bearer long-lived key against `https://asr.api.speechmatics.com/v2/jobs` (multipart `config` + `data_file`),
  poll `GET /v2/jobs/{id}`, `GET /v2/jobs/{id}/transcript?format=json-v2`, then `DELETE /v2/jobs/{id}`.
- Key test: `GET https://asr.api.speechmatics.com/v2/jobs?limit=1`.
- Whitelist: `https://mp.speechmatics.com`, `https://asr.api.speechmatics.com`, `wss://eu.rt.speechmatics.com`,
  `wss://us.rt.speechmatics.com`.
